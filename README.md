🛰️ SHANU GPS TRACKER V2

Phishing Awareness & Security Simulation Tool

SHANU GPS TRACKER V2 is an educational cybersecurity project designed to demonstrate phishing-style social engineering scenarios and raise awareness about online privacy and location-sharing risks.

Key Features

- Phishing awareness demonstrations
- Social engineering education
- Consent-based GPS demonstrations
- Location-sharing privacy awareness
- Flask-based web interface
- Mobile-friendly demonstration pages

📱 Termux Installation & Setup

Step 1 — Update Termux

pkg update && pkg upgrade -y

Step 2 — Install Requirements

pkg install git python -y

Step 3 — Clone Repository

git clone https://github.com/shanudevil558-collab/SHANU-GPS-TRACKER.git

Step 4 — Open Project Folder

cd SHANU-GPS-TRACKER

Step 5 — Install Python Dependencies

pip install -r requirements.txt

Step 6 — Give Launcher Permission

chmod +x menu_fixed.sh

Step 7 — Launch the Project

bash menu_fixed.sh

🔐 Privacy & Security

- Location sharing must always require explicit user consent.
- Clearly disclose what information is collected and where it is sent.
- Use only authorized educational demonstrations.
- Never collect credentials or track people without permission.
- Keep API keys, private information and logs out of public repositories.

⚠️ Disclaimer

This project is intended strictly for cybersecurity education, phishing awareness and authorized security demonstrations. It must not be used for deceptive tracking, credential theft or unauthorized data collection.
