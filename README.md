🌌 About the Project

SHANU GPS TRACKER V2 is a Python Flask-based educational project that demonstrates browser-based GPS location sharing with explicit user consent.

It includes a mobile-friendly interface, multiple themed demonstration pages and a terminal-based launcher.

✨ Features

- 📍 Browser-based GPS location sharing
- 🔐 Explicit user consent
- 🐍 Python Flask backend
- 📱 Mobile-friendly interface
- 🎛️ Interactive terminal menu
- 🌐 Localhost application mode
- ✅ GPS coordinate validation
- 📊 Server-side location information output
- 🎨 Multiple themed demonstration pages

🧰 Requirements

- Android device
- Termux
- Python 3
- Git
- Internet connection for installation

📥 Installation — Termux

1. Update Termux

pkg update && pkg upgrade -y

2. Install dependencies

pkg install git python -y

3. Clone the repository

git clone https://github.com/shanudevil558-collab/SHANU-GPS-TRACKER.git

4. Enter the project directory

cd SHANU-GPS-TRACKER

5. Install Python requirements

pip install -r requirements.txt

6. Give launcher permission

chmod +x menu_fixed.sh

---

🚀 How to Run

Option 1 — Main Menu

Start the interactive launcher:

bash menu_fixed.sh

Or:

./menu_fixed.sh

Follow the options displayed in the terminal.

🔒 Privacy & Security

- Location sharing must always be voluntary.
- Clearly disclose that submitted GPS information is sent to the SHANU application server.
- Never attempt to obtain someone's location without their informed permission.
- Never use the project for covert tracking.
- Do not publish real GPS coordinates, private logs, credentials or access tokens.
- Use responsibly for educational and authorized testing.
